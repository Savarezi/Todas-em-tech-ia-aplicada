# Curso de Inteligência Artificial

Repositório criado para organizar meus estudos, atividades práticas, projetos e aprendizados ao longo do curso de Inteligência Artificial.

## 📚 Sobre o curso

Este repositório reúne minha jornada de aprendizado em Inteligência Artificial, passando desde os fundamentos de prompting e automação até aplicações mais avançadas de IA, dados, agentes e estratégias para negócios.

Ao longo do curso, serão desenvolvidas atividades práticas e registros dos conteúdos estudados, permitindo acompanhar minha evolução durante a formação.

## 🎯 Objetivo

Desenvolver conhecimentos práticos em Inteligência Artificial e aprender a utilizar diferentes ferramentas e estratégias de IA para resolver problemas, automatizar processos, trabalhar com dados e criar soluções aplicadas a diferentes contextos.
