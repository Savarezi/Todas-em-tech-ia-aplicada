# 💜 Todas em Tech Futuro+ - Semana 14: Escala e Otimização

Repositório dedicado aos estudos, frameworks e entregas práticas da **Semana 14**, focada em transformar protótipos locais em aplicações web prontas para o mundo (*Deploy*), segurança de dados, monitoramento de performance (*Core Web Vitals*), gestão de custos e planejamento de backlog (*Roadmap*).

---

## 📅 Resumo dos Conceitos da Semana

* **Deploy e Produção:** Transição do ambiente local (*localhost*) para a nuvem pública utilizando Vercel e GitHub, separando o código dos dados confidenciais.
* **Segurança de Dados e Variáveis de Ambiente:** Proteção contra vazamentos de chaves de API, uso correto do arquivo `.env` e ativação obrigatória de políticas de segurança no banco de dados (*Row Level Security - RLS*).
* **Performance e Monitoramento:** Análise de gargalos no banco de dados, métricas de interface (*LCP, INP, CLS*) e uso de agentes para acompanhamento de limites e consumo (*Rate Limit*).
* **Custos, Backlog e Roadmap:** Priorização de pendências utilizando critérios estruturados (como matrizes de impacto/esforço) e organização em ciclos (*Now, Next, Later*).
