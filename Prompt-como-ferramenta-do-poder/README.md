# Prompt como Ferramenta do Poder

Este diretório reúne o material teórico, prático e o projeto desenvolvido sobre engenharia de prompt, inteligência artificial e o impacto de gênero no mercado de tecnologia e dados.

---

## 📂 Estrutura da Pasta
* **`aula-prompt-engineering.md`**: Conceitos fundamentais de Inteligência Artificial, Harness Engineering, a estrutura PAPO e as técnicas avançadas de Prompt (Zero-shot, Few-shot, ReAct e RAG).
* **`projeto-lideranca-financeira.md`**: Projeto prático integrando inteligência artificial, mentoria e uma auditoria completa de equidade salarial em Data Science no Brasil com base em dados reais.
