## 🛠️ O que compõe este projeto?
1. **O Aplicativo:** Protótipo funcional desenvolvido com autonomia através de IA (Vibe Coding), conectado a um banco de dados persistente no Supabase.
2. **Prompt do Lovable (`prompt_lovable.md`):** O comando estruturado utilizado para gerar a arquitetura e as telas do aplicativo na plataforma.
3. **Apresentação em HTML (`apresentacao.html`):** Slide deck interativo e moderno em HTML apresentando a solução.
4. **Documentação Técnica (`documentacao.md`):** Detalhes de tabelas, fluxos de login e guias de suporte com o Inspecionar (F12).

---

## 📂 Arquivos Disponíveis
* `prompt_lovable.md` — Prompt original utilizado na construção do app.
* `apresentacao.html` — Apresentação visual interativa.
* `documentacao.md` — Especificações técnicas e guias de validação.
