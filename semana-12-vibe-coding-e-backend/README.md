# 💜 Todas em Tech Futuro+ - Semana 12: Vibe Coding, Backend & Autenticação

Repositório dedicado aos estudos, conceitos práticos e entregas da **Semana 12**, abordando a transição de protótipos visuais (*frontend*) para aplicações persistentes com banco de dados, controle de acesso e ferramentas de investigação de erros.

---

## 📅 Resumo dos Conceitos da Semana

* **Fundamentos de Banco de Dados e Backend:** Compreensão de como os dados deixam de ficar salvos apenas na memória temporária do navegador (`localStorage`) e passam a ser persistidos de forma segura em tabelas estruturadas.
* **Supabase & Conector MCP (Model Context Protocol):** Utilização do Supabase como serviço integrado de backend, banco de dados e autenticação, conectado de forma ágil via IA.
* **Autenticação e Permissionamento:** Estabelecer camadas de segurança (fechaduras de tela e regras de acesso no banco de dados via RLS - Row Level Security) para definir quem pode entrar e o que pode fazer no sistema.
* **Investigação de Bugs com o Inspecionar (F12):** Guia prático de uso do DevTools (abas *Console* e *Network*) para leitura de códigos de status HTTP e mensagens de erro sem precisar programar.
